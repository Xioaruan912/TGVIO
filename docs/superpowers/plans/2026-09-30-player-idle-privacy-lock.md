# Player 一分钟无操作自动隐私锁定计划

## 行为合同

- 短视频：解锁后连续 60 秒无真实用户操作，遮住画面、暂停并强制静音；播放进度、自动加载和预热不是用户操作。
- 长视频：实际正常播放时不计时；暂停、结束、加载/缓冲等未播放状态下，60 秒无操作后执行相同隐私锁定。停止播放时给完整 60 秒宽限。
- 点击、触摸/拖动、滚轮、键盘和输入属于操作；锁定后仅明确播放操作可解锁，普通活动不自动解锁。
- 解锁仍保持静音，需要用户主动开启声音。长视频继续播放例外不放宽已有后台隐私策略；PiP 等已有例外只在正常播放时有效，锁定后停止并退出 PiP。
- 网页无法强制手机系统锁屏；此处锁屏指 Player 隐私遮挡。

## 实施与验收

1. 新建可注入时钟的 IdlePrivacyController，共用固定 60000ms 合同；监听用户事件但不监听媒体 timeupdate/scroll 来刷新期限。
2. 接入短 Feed 的解锁、锁定、长视频页面切换与后台生命周期；长播放器独立计时，根据真实 playing/waiting/pause/ended/error/seeking 等事件更新状态。
3. 锁定统一先静音再暂停，记住静音状态；处理晚到的声音确认 Promise，避免锁定后恢复声音。
4. 自动测试精确 59.999/60 秒、重复操作、长视频持续播放、暂停后计时、恢复播放取消期限、销毁和计时器延迟；隔离 Chrome 检查遮挡、静音与长播放器媒体事件接线。
5. 前端测试/构建、Python 回归、架构/源码门禁通过后提交推送；唯一 Player 候选镜像传 VPS，备份并演练数据库，保留旧镜像/环境/源码，Player-only 切换和 HTTPS/Range 后验。
6. 发布证据与未验收真机范围入库；不重启 Bot、不修改数据库迁移、不安装新依赖。
