# 2026-10-01 Player 前端改版交接

## 范围与现状

接续标准化阶段，用户已提供浅色蓝青应用外壳与内容封面设计。
本轮仅修改/验证 WSL Debian /root/TGVIO 的 Player Web；不部署、不重启，
不改 Bot、生产媒体、反向代理或公网监听。Git/VPS 运行身份与源码分开记录。

当前页面已有四区导航、独立控制区、统一封面组件、隐私/声音/续播控制器。
旧卡片标题与时长绝对定位竞争、图片失败重试覆盖信息，网格没有充分考虑
容器，手动隐私入口藏在菜单。封面有服务端可选字段及真实代理接口，
但老归档没有 cover 声明时不会自动得到静态帧。

## 实现

- cover-tile.ts：标题与元信息独立行、状态准确、预览 aria-pressed、
  20 秒有界加载与一次自动重试、失效回调隔离、显式销毁。
- cover-load-queue.ts：临近可见的静态 img 使用共用两请求预算。
- cover.css：9:16/16:9、按容器响应网格、随信息高度变化的局部渐变、真实图片原色、
  独立重试与选择控件、可见焦点、减少动画。
- library.ts / favorites.ts：共用卡片生命周期与空状态；保留层级、
  选择上限和分页、收藏与备份各自语义。
- long.ts / api.ts / types.ts：明确 cover_url 类型，长片关闭请求取消、
  去重/无新增退出/三次自动补页/1000 预算、失败重试与返回焦点；
  续播位置紧凑展示，已删除媒体不被迟到的续播响应恢复。
- ui.ts / media-actions.ts / large.ts：隐私锁常驻，删除分隔，
  随机文案准确，长播放器声音状态可读，登录提交/错误明确。
- styles/shell.css / overlay.css / large.css / feed.css / settings.css：
  浅色令牌沿用、实色隐私色统一、小屏/横屏、安全区与登录缩高。
- settings-view.ts：清晰度来自实际当前媒体，屏幕常亮不支持时准确说明。
- Node/浏览器测试补加载期限、销毁、预览、队列、长片失败/分页/返回；
  实际应用验收使用隔离视频帧、临时端口/浏览器 profile 与 HTTP Range。
- player/AGENTS.md 固化封面、并发、生命周期、常驻隐私和六视口规则；
  当前设计单独放 development，不把 AGENTS 膨胀为执行日志。

## 封面供给与未验收

验收使用本地 FFmpeg testsrc2 生成的短/长 MP4 及提取 PNG 帧；属于合成测试
视频内容，不是生产片库。另有明确缺图、404、未知时长及长标题隔离样本。
生产封面覆盖率未抽样，不编造比例；前轮证据说明 VPS Player 运行旧版本，
本轮没有切换服务。后端已具备静态封面合同，无需本轮新增接口。
旧库补封面仍依赖正常归档生成/manifest/catalog 供给，本轮未执行全库处理。
图片缺失显示“暂无封面”，加载失败保留播放及重试入口；两者不混淆。
收藏列表接口不携带逐项备份状态，因此不制造“已备份”标记；
现有设置入口继续展示真实备份汇总状态与已有操作。

Android/iOS 真机、真实软键盘、生产认证/源媒体/Range 尚未验收；
Chrome resize/模拟移动视口不代表真机通过。隐私是网页遮挡，不是系统锁屏。
